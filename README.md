# Task 22 - Tailwind Hero Landing Page

## Project Name: Project (AI Workspace)

### What I Built
A modern hero landing page for an AI-powered workspace platform.

### Features Included:
- ✅ Sticky navigation bar (position: sticky)
- ✅ Dashboard preview with floating cards (position: relative + absolute)
- ✅ Fixed chat widget (position: fixed)
- ✅ Responsive design (mobile-first)
- ✅ Mobile hamburger menu

### Positioning Types Used:

| Position | Where | Why |
|----------|-------|-----|
| **sticky** | Navigation header | Stays at top when scrolling |
| **relative** | Dashboard container | Parent for absolute positioned cards |
| **absolute** | Floating cards (Team Activity, Quick Start) | Places cards outside the main dashboard |
| **fixed** | Chat widget | Always visible in bottom-right corner |

### Responsive Breakpoints:

| Breakpoint | Device | Changes |
|------------|--------|---------|
| **390px** | iPhone SE/small phones | Smaller text, tighter spacing |
| **768px** | Tablets | 2-column layout, larger cards |
| **1280px** | Desktop | Full width, larger typography |

### Expected Output Matched:
- ✅ Logo: "Project" with 🔗
- ✅ Headline: "Write, plan, share. With AI at your side."
- ✅ Subheadline: Workspace description
- ✅ Buttons: "Get AI free" and "Request a demo"
- ✅ Navigation: Product, Solutions, Resources, Pricing, Log in, Get AI free
- ✅ Team Activity card
- ✅ Create a project button
